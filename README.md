架空の成人AIキャラクターのサンプルです。黒髪ボブ、ぱっつん前髪、小ぶりな鼻、丸みのある顎の顔を共通の基準にしています。SNSへの実投稿は行っていません。

18のコーデを、日本語の投稿文・画像見出し付きで表示。写真をタップすると拡大できます。ショート動画は新しい黒ワンピースの画像からローカル生成し、字幕・明るさ補正・60fpsの動き補間を加えています。

旧サンプルの画像・動画・詳細ページは公開対象から削除しました。
